The title of this project is Payroll Processing.
In this project we were able to calulcate pay for the employees as well as makesure they were paid for any overtime that they worked.
We were also able to calculate the federal tax, social security, and medicare that would be deducted if any. This helped us to pay employees and allow their wages to be calculated correctly.
The technology that was used was our Github account and Visual Studio Code in which we used html and javascript to run the code. 
In order to run this code you will need to have node.js installed and open your terminal to install the project folder and run the code to get the output of the code.
I learned how to create functions for different tasks, how to apply conditional logic statements, formatting numbers so they return the correct format, and overall breaking down a big project into smaller parts to make it easier to handle.
